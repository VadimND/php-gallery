# Адаптивная карусель слайдов на основе Swiper.js с LightGallery
### Блок для редктора CMS WordPress реализован в виде плагина. Не нуждается в сборке и серверном рендеринге. Тестировано на версии 6.9.

## Преимущества галереи
- [x] Не требует дополнительных зависимостей и лицензий на коммерческое использование
- [x] На одной странице можно создавать несколько галерей
- [x] При заполнении галереи не требуется загружать отдельно превью, система сама генерирует их
- [x] Автоматическая генерация alt для изображений, где атрибут не заполнен, вывод caption на основе alt

## Использование
* Установить и активировать плагин Wordpress
* На странице редактирования выбрать блок Swiper Gallery
* Загрузить полноразмерные картинки, указать атрибуты ALT
* Сохранить и проверить результат
