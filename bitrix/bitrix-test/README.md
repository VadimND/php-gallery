# Тестовое задание: Каталог «Связанные товары» (Bitrix)

## О проекте

Небольшой фрагмент интернет-магазина на Bitrix Framework. Реализован модуль
`custom.catalog` и компонент `custom:catalog.related`, который выводит блок
**«Похожие товары»** на карточке товара.

Связанные товары хранятся в множественном свойстве `RELATED_PRODUCTS`
(привязка к элементам) у товара каталога. Компонент должен показывать
связанные товары с рассчитанной ценой и скидкой.

Проект уже работает и находится в эксплуатации. Недавно с блоком связанных
товаров начались проблемы — им и предстоит заняться.

## Бизнес-контекст

Инфоблок каталога (`IBLOCK_ID = 2`) содержит товары со свойствами:

| Код свойства        | Тип                    | Назначение                          |
|---------------------|------------------------|-------------------------------------|
| `RELATED_PRODUCTS`  | привязка к элементам, множественное | список связанных товаров |
| `DISCOUNT_PERCENT`  | число                  | скидка на товар, %                  |
| `IS_PROMO`          | список Y/N             | участвует ли товар в акции          |
| `IN_STOCK`          | список Y/N             | наличие товара                      |
| `PRICE`             | число                  | базовая цена товара                 |

**Бизнес-правила для блока «Похожие товары»:**

1. Показываются только **активные** товары (`ACTIVE = Y`).
2. Показываются только товары **в наличии** (`IN_STOCK = Y`).
3. Цена показывается **с учётом скидки**:
   - скидка товара из свойства `DISCOUNT_PERCENT`;
   - плюс персональная скидка пользователя (может приходить в промо-ссылке);
   - суммарная скидка не может превышать **90 %**.
4. Список отсортирован по **итоговой цене по возрастанию**.

## Требования к окружению

- PHP 8.1+
- MySQL / MariaDB 10.x
- (опционально) Docker + docker-compose

Полное развёртывание ядра Bitrix **не требуется**. Для быстрой проверки
логики в проект включён лёгкий запускатель, эмулирующий нужную часть
Bitrix API.

## Запуск

### Вариант A — быстрый (без ядра Bitrix)

```bash
./run_local.sh
```

Скрипт подключит код модуля и выведет результат работы блока связанных
товаров для товара с `ID = 100`.

### Вариант B — Docker (БД + PHP)

```bash
docker-compose up -d
# seed.sql подхватывается автоматически при первом запуске БД
docker exec -it bitrix_test_php bash
```

Данные каталога описаны в `database/seed.sql`.

## Доступ / данные

- Основной товар: **ID = 100** («Смартфон Alpha»).
- Его связанные товары: ID **101–106**.
- Данные для воспроизведения — в `database/seed.sql` и `tests/fixtures.php`.
