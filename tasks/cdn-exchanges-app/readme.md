# Задание на понимание ООП

Задание на понимание концепции ООП, умение использовать базовые средства для реализации ООП подхода.

Необходимо, используя ООП подход, описать обработчик, который предназначен обеспечивать взаимодействие с различными CDN сервисами для обмена файлами. Работа с CDN сервисами должна осуществляться через единственный ключевой класс, при этом API у всех сервисов разное.

Связь между файлом приложения и файлом на CDN осуществляется по уникальному идентификатору файла в приложении.
Модель необходимо реализовать без детальной проработки работы с API каждого сервиса.
Количество CDN серверов и их API известно и не требует уточнения.

Минимальный набор методов ключевого класса:
	a.	проверка существования файла на сервере
	b.	отправка файла на CDN
	c.	удаление файла на CDN
	d.	получение актуальной CDN ссылки на файл

Результатом выполнения задания является подготовленный архив с php файлами, реализующими ТЗ.


## Последовательность выполнения задания

1) Создать единый интерфейс с 4-мя методами для последующей реализации в классах.
2) Создать классы для конкретных провайдеров с эмуляцией методов работы.
4) Сделать один контроллер для всех провайдеров.
5) Создать точку входа для работы с контроллером и протестировать вывод.
